# Sourdough Co-founder

A ready made Claude Code setup for running a sourdough TikTok and Instagram channel. Open it in VS Code, start Claude, and you have a co-founder that researches trends, plans your week, writes hooks and scripts, writes captions, edits video, and keeps track of what's working.

## Get your own copy

1. Make a free GitHub account at github.com if you don't have one.
2. On this page, click the green **Use this template** button, then **Create a new repository**.
3. Name it whatever you like (e.g. `my-sourdough-channel`), set it to **Private**, and click **Create repository**.
4. Follow [SETUP.md](SETUP.md) to get it running on your computer.

## What's inside

- `CLAUDE.md`: the co-founder brief. Claude reads this every time it starts.
- `.claude/skills/`: the skills (research, planning, scripts, captions, video editing, idea stress tests).
- `brand/`: your brand, voice and content pillars. Filled in on day one by `/onboard`.
- `content/`: ideas backlog, scripts, and a log of everything posted.
- `research/`, `brainstorms/`, `videos/`: where the work gets saved.

## First thing to type

After setup, open Claude in this folder and type:

```
/onboard
```

It asks about 10 questions and fills in everything else.
